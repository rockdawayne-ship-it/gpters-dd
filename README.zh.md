> 不必把长日志或截图整段粘进对话，也能交给 Claude Code。

用 Claude Code 干活时你总在粘贴：出问题时丢错误日志，做东西时给参考，想要的效果就截屏说明。`dd` 直接从剪贴板读取内容，存进本地文件，只把必要的信息传给对话——大块材料还会在后台分析，只带回结论。

## 快速开始

### 1. 添加市场

```
/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
```

### 2. 安装

```
/plugin install dd
```

### 3. 重启 Claude Code

（新命令需要重启后才会注册。）

### 4. 上手使用

先把内容放到剪贴板，再输入 `/dd`（或 `/ㅇㅇ`）加上你的请求——无需粘贴：

- **图片 — Windows:** 用 `Win`+`Shift`+`S` 截屏，然后 `/dd 为什么显示成这样？`（截图已经在剪贴板里）
- **图片 — macOS:** 用 `Shift`+`Cmd`+`4` 截屏，然后 `/dd 照这个参考做一个`（一次性设置：让截图保存到剪贴板——截屏工具栏 `Shift`+`Cmd`+`5` → **选项** → **存储到：剪贴板**）
- **长文本 / 错误日志:** 复制后 `/dd 这是什么错误？` —— 大段文本不会整个进入对话，会话保持轻量
- **不带请求:** 直接 `/dd` —— 读取剪贴板并顺着对话继续处理

在韩文输入法下直接敲 `/dd` 也行——它会打出 `/ㅇㅇ`，效果相同。无需切换输入法。

## 为什么是 dd

用 Claude Code 干活时，要粘贴的东西没完没了。调试时丢错误日志，做东西时给参考，截个图说明想要的感觉。但把这些全都直接粘进对话，会撞上两个问题。

长文本会吃掉对话。大日志粘一次就一直留在那里占地方，每一轮都被重新读取，会话就慢慢变慢、变贵。`dd` 把原文放进文件，只递给 Claude 一份简短摘要，任务需要时才多读一点。

图片经常根本粘不进去。取决于你的环境，Claude Code 可能收不到粘贴的图片。`dd` 直接读剪贴板，截屏后敲 `/dd` 就行。复制的图片文件也会以真实图像进来，而不是文件图标。

你也不用再重复"我刚复制的那个错误"或"上面那个参考"了。如果 `dd` 抓错了东西（剪贴板没有时间戳），它会先展示抓到的内容并向你确认。

`dd` 这个名字没有任何含义。用得频繁却每次都要打一长串太麻烦，所以就选了能快速连敲两下的两个字母。（在韩文输入法下这两个键会打出 `ㅇㅇ`，同样有效。）

## 工作原理

```
复制 / 截屏
   → /dd [请求]
   → dd_clipboard.py 把当前剪贴板捕获到 ~/dd/<日期>/<id>/
       · 文本 → content.txt   图片 → image.png   + manifest.json
   → Claude 只读 manifest 摘要（不读全文）
   → 展示抓到了什么；不对劲就先确认，没问题就直接干活
```

系统剪贴板只保留最近一次复制（没有历史）。`dd` 总是捕获当前这一项，在预览中遮盖敏感信息，并自动清理超过 7 天的捕获。

## 主要功能

| 功能 | 说明 |
|------|------|
| 文本与图片捕获 | macOS / Windows / WSL / Linux 剪贴板，文本或图片 |
| instruction 模式注入 | 每次 `/dd` 都通过 `${CLAUDE_PLUGIN_ROOT}` 捕获——对所有人生效 |
| 确认门 | 仅当剪贴板内容与请求无关或含糊时，才在动手前确认 |
| 惰性读取 | 按 `size_class` 分级读取，超大粘贴不会淹没上下文 |
| 敏感信息遮盖 | `api_key`、`Bearer`、`sk-`、`ghp_`、`xoxb-` 等在预览中打码 |
| 自动清理 | 超过 `DD_RETENTION_DAYS`（默认 7 天）的捕获在每次运行时删除 |
| 后台分析 | 大日志、大图片交给子代理分析，只把结果放进对话 |
| 用你的语言回答 | 按请求的语言回答；没有请求时按对话语言 |

## 命令

| 命令 | 说明 |
|------|------|
| `/dd [请求]` | 捕获当前剪贴板并进行处理 |
| `/ㅇㅇ [请求]` | 与 `/dd` 相同（韩文输入别名） |

### 自然语言触发

- "방금 캡처한 거 분석해줘", "이 레퍼런스로 만들어줘", "스크린샷 드롭"
- "drop clipboard", "use what I copied", "this screenshot"

## 环境要求

- [Claude Code](https://docs.anthropic.com/claude-code) CLI
- Python 3（仅标准库）
- **macOS**: 开箱即用（`pbpaste` / `osascript`）
- **Windows / WSL**: PowerShell（系统自带）—— 经用户验证
- **Linux**: 需安装剪贴板工具（`xclip` / `wl-clipboard`）并有图形会话
